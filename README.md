# Copilot

A collection of Copilot-related tools, skills, and other helpers that come out of my daily work with Microsoft 365, SharePoint, and AI assistants.

Everything here started as a real problem I had to solve. When something proved useful more than once, it ended up in this repo.

## Contents

### Skills

Skill definitions live in [skills/](skills/), documentation in [docs/skills/](docs/skills/).

| Skill | Description |
|---|---|
| [sharepoint-page-assets-cleanup](docs/skills/sharepoint-page-assets-cleanup/) | Copilot in SharePoint site skill that finds the images a modern page uses, identifies unused files in its `SiteAssets/SitePages/<Page>` folder, and safely recycles them after confirmation. |
